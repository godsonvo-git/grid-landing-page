# Grid Layout Website

A responsive grid-based landing page built as part of a Frontend Mentor challenge.

This project was created to practice CSS Grid, Flexbox, responsive layouts, spacing, borders, and overall page structure while recreating the provided design as closely as possible.

## 📖 What I Learned

While building this project, I practiced and improved my understanding of:

- Creating layouts using **CSS Grid**
- Creating multi-column and multi-row grid structures
- Using `grid-template-columns` and `grid-template-rows`
- Using `fr` units to divide available space
- Combining **CSS Grid and Flexbox**
- Creating full-width sections
- Working with borders and spacing
- Structuring a webpage into reusable sections
- Building layouts that adapt to different screen sizes
- Using external icon libraries

## 🧩 Features

- Clean grid-based layout
- Responsive structure
- Two-column main hero section
- Four individual statistic cards
- Navigation bar
- Footer section
- Minimalistic visual design
- Uses Boxicons for interface icons
